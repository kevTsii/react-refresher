# React Refresher

A collection of mini-projects built while revisiting React concepts, as part of a Next.js learning roadmap.

Each project targets a specific React concept or set of concepts, from fundamentals to more advanced patterns.

## Projects

| Folder | Concepts covered | Description |
|---|---|---|
| `crud-j1` | State, props, components | Todo app with full CRUD operations (add, edit, delete, filter) |
| `world-search-j2` | useEffect, useRef, API calls | Real-time country search with debounce via REST Countries |

## Structure

Projects follow the naming convention `<concept>-j<day>` (e.g. `crud-j1` = CRUD, day 1).

Each subfolder is a standalone React app with its own `package.json`.

## Running a project

```bash
cd <project-name>
npm install
npm start
```
